A 4 KB alpha-beta chess engine in pure Python: a 0x88 board, quiescence search, transposition table and killer-move ordering under a fixed node budget (never a clock, so replays play the same moves). It plays the house gauntlet through the make.fun env, one move at a time.

## Run it

```sh
python3 main.py
```
